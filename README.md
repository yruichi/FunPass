# 🐍 FunPass

A Simple Python-Based Amusement Park Ticketing System

---

## 📌 About the Project

**FunPass** is a simple desktop-based amusement park ticketing system developed as a **first-year BSIT project (2023)**. The system allows administrators and employees to manage amusement park ticket bookings, customer information, and ticket records through an easy-to-use interface.

The project was created to replace manual ticketing with a faster and more organized digital solution while introducing basic Python programming concepts.

## 🎯 Problem & Target Users

Many small amusement parks still rely on manual ticketing, which can result in long queues, misplaced records, and inefficient transaction management.

**FunPass** is designed for:

- Employees (Ticketing Staff)

## ⚙️ Installation Guide

### 1. Clone the repository

```bash
git clone https://github.com/your-username/funpass-python.git

cd funpass-python
```

### 2. Install dependencies

```bash
pip install pillow
```

### 3. Initialize the database

```bash
python database.py
```

### 4. Run the application

```bash
python main.py
```
